## 1. Νέες/Ενημερωμένες υπηρεσίες στο `services.tsx` και `services.$slug.tsx`

Προσθήκη 4 νέων slugs με βάση το υλικό:

- **`cv-interview`** — *Βιογραφικό & Προετοιμασία Interview*
  Σύνταξη/οργάνωση CV και mock-interview coaching για αυτοπεποίθηση και στρατηγική παρουσίαση.
- **`o-xartis`** — *Ο «Χάρτης»*
  Signature πρόγραμμα αυτογνωσίας: ερωτήσεις, συζητήσεις, ασκήσεις για ξεκαθάρισμα ταυτότητας, στόχων και επόμενων βημάτων.
- **`agkyrosi`** — *Αγκύρωση (NLP τεχνική)*
  Άσκηση σύνδεσης ερεθίσματος με ηρεμία/εσωτερική δύναμη — άμεση διαχείριση άγχους.
- **`ypo-idiotites`** — *Υπο-Ιδιότητες (NLP τεχνική)*
  Δουλειά με τα διαφορετικά «μέρη» του εαυτού για αλλαγή συνηθειών (κάπνισμα, γλυκά, σοκολάτα κ.ά.).

Επίσης: εμπλουτίζω τα υπάρχοντα `career-orientation` και child slugs με τα δύο κείμενα *Επαγγ. Προσανατολισμός για εφήβους / για ενήλικες* (ως δύο ενότητες ή split σε `career-orientation-teens` + `career-orientation-adults` — προτείνω **split** για καθαρότερο SEO).

→ Ενημέρωση grid στο `services.tsx` με τα νέα cards.
→ Ενημέρωση `services.$slug.tsx` map με intro/sectionBody/how/benefits για κάθε νέα υπηρεσία (γραμμένα στο ύφος των υπαρχόντων).

## 3. Νέα ενότητα **Άρθρα / Blog**

Νέες routes:
- `src/routes/arthra.tsx` → `/arthra` (index λίστα άρθρων, editorial grid)
- `src/routes/arthra.$slug.tsx` → `/arthra/:slug` (σελίδα άρθρου με H1, eyebrow, body, CTA)

Seed περιεχόμενο (από τα uploaded κείμενα ως πρώτα 4 άρθρα):
1. *Επαγγελματικός Προσανατολισμός για εφήβους*
2. *Επαγγελματικός Προσανατολισμός για ενήλικες*
3. *Αγκύρωση — μια NLP τεχνική για άμεση ηρεμία*
4. *Υπο-Ιδιότητες — αλλαγή συνηθειών μέσα από τα μέρη του εαυτού*

Δομή δεδομένων: `src/lib/articles.ts` με `{ slug, title, excerpt, body, category, readingTime }`. Editorial styling που ταιριάζει με την υπάρχουσα παλέτα (navy/ivory/gold, font-serif headings).

Προσθήκη link «Άρθρα» στο `SiteHeader.tsx` και στο `SiteFooter.tsx`.
Προσθήκη `head()` meta σε κάθε route + canonical + JSON-LD (`Article` schema) στις σελίδες άρθρων για SEO.
Teaser block στο home (`index.tsx`) με τα 3 πιο πρόσφατα άρθρα — ανάμεσα σε «Areas Served» και «CTA Strip».

## Ερωτήσεις πριν προχωρήσω

1. **Επαγγ. Προσανατολισμός**: να γίνει split σε δύο ξεχωριστές υπηρεσίες (έφηβοι/ενήλικες) ή να μείνει ως μία με δύο ενότητες μέσα;
2. **Άρθρα**: τα 4 κείμενα είναι αρκετά σύντομα (παράγραφος έκαστο). Να τα χρησιμοποιήσω αυτούσια ή να τα **επεκτείνω** σε πληρέστερα άρθρα 400-600 λέξεων στο ίδιο ύφος;
3. **Φωτογραφίες**: τα `parsed-documents://...page_1.jpg` είναι screenshots των Word σελίδων (όχι χρήσιμα). Θέλεις να κάνω **AI-generated cover images** για κάθε άρθρο (editorial style που ταιριάζει στη μάρκα);
4. **About**: να συμπεριλάβω και την **προϋπηρεσία** εκτός coaching (π.χ. styling, retail, διαιτολογία) ή μόνο τη σχετική με coaching/ψυχολογία;
